What this page proves

SAML PASS proves federation authentication was accepted. It does not automatically prove that AcmeHR local-account creation succeeded.

JIT FAILED is an application lifecycle failure after federation. Do not change the SAML signing certificate, Audience, Recipient, or AuthnRequest signature when those checks already passed.

On a later login, JIT MATCHED proves AcmeHR found the existing local account before considering new-account creation.
