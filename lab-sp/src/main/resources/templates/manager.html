What this proves

The SAML login was already accepted before this decision. AcmeHR then read the validated groups claim, found the exact allowlisted value AcmeHR-Managers, mapped it to MANAGER, and allowed access to this page.

The SAML login was already accepted before this decision. AcmeHR did not find the exact allowlisted manager group in the validated claims, so it did not map MANAGER and returned an authorization denial.

This is application authorization. It is separate from Okta authentication, SAML validation, and Okta application assignment.
